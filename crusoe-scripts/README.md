# crusoe-scripts

Standalone scripts from the Crusoe Cloud Support team. Each subdirectory is
self-contained and carries its own README with the full procedure.

| Path | What it is |
|---|---|
| [`emudhra/`](emudhra/) | Removes the distrusted eMudhra root CAs (CVE-2026-111943) from the CMK CoreDNS, konnectivity-agent, kube-state-metrics, and cert-manager add-on images with one `kubectl`-driven script |
